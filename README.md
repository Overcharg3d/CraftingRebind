# CraftingRebind
CraftingRebind adds extra recipe book shortcuts that aren't in vanilla Minecraft, each with its own keybind. They work on every screen that has a recipe book, including screens added by other mods.

### Shortcuts
|Shortcut|Action|Default Keybind|
|-|-|-|
|Toggle Recipe Book|Toggles the recipe book on the side.|N|
|Toggle Craftable Only|Toggles the craftable only filter.|V|
|Cycle Category Tabs|Cycles through the category tabs.|B|
|Focus Search Bar|Moves your focus to the search bar.|/|

## Requirements
- **Minecraft:** 26.1 - 26.4
- **Fabric:** 0.20.1 + **Fabric API**
- **Java:** 25
